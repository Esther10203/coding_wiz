# Practice: Structs and memory

### 6.1 One sale ⏱️ 8 min

Define `struct Sale` with `double temp` and `int sales`. Fill one and print `temp=... sales=...`.

### 6.2 Three sales ⏱️ 10 min

Make `struct Sale days[3]`. Fill three rows from the temperature/sales table. Print each row in a loop.

### 6.3 Heap array ⏱️ 12 min

`malloc` an array of 5 `int`s. Fill it with 1..5, print it, `free` it, and set the pointer to `NULL`. If `malloc` returns `NULL`, stop.

### 6.4 Size at run time ⏱️ 10 min

Read `n` (between 1 and 20). Allocate `n` integers, read them, print their sum, then `free`.
