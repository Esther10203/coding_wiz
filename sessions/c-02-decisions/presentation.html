C · Lesson 2: Decisions and loops

Beginner

Last time

  • main starts the program
  • int, double, char are boxes
  • printf and scanf move values in and out

if / else

if (score >= 10) {
    printf("Pass\n");
} else {
    printf("Try again\n");
}

>= asks a yes/no question. The braces are the answer.

Compare carefully

Symbol Means
== equal
!= not equal
< > smaller, bigger
&& and
|| or

= stores a value. == compares two values.

while: repeat while true

int n = 3;
while (n > 0) {
    printf("%d\n", n);
    n = n - 1;
}

If the test never becomes false, the loop never ends.

for: count on purpose

for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}

Start at 1. Keep going while i <= 5. Add 1 each time.

Try it · 2 min

Print the numbers 1 to 10 with a for loop. Then print only the even ones (i % 2 == 0).

Remember

  • if chooses a path
  • == compares, = stores
  • for is a counted loop. while repeats while a test is true

Practice: Decisions and loops

2.1 Pass or fail ⏱️ 6 min

Read a score with scanf. Print "Pass" when it is 50 or more, otherwise "Fail".

2.2 Fizz ⏱️ 8 min

Loop from 1 to 20. If the number divides by 3, print "Fizz". Otherwise print the number. Use %.

2.3 Sum 1 to N ⏱️ 10 min

Read n. Add the numbers from 1 to n and print the total.

Answer shape
int total = 0;
for (int i = 1; i <= n; i++) {
    total = total + i;
}
