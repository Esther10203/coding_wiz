# Practice: Functions

### 3.1 Square ⏱️ 6 min

Write `int square(int n)` and print `square(6)`.

### 3.2 Max of two ⏱️ 8 min

Write `int max2(int a, int b)`. Test it with 3 and 9, then with 9 and 3.

### 3.3 Celsius to Fahrenheit ⏱️ 10 min

`double c_to_f(double c)` returns `c * 9.0 / 5.0 + 32.0`. Read a Celsius value and print the result with one decimal place.

### 3.4 Is even ⏱️ 6 min

`int is_even(int n)` returns 1 when `n % 2 == 0`, otherwise 0. Print "even" or "odd" from `main`.
